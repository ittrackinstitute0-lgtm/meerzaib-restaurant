# 👑 MEERZAIB RESTAURANT

Welcome to the official repository of **MEERZAIB RESTAURANT** — a luxury royal fine dining website with interactive button animations, dynamic food ordering system, table reservation suite, customer reviews, and a full-fledged Staff & Manager Admin Panel.

---

## 🌟 Key Features

### 1. 🍽️ Customer Website (`index.html`)
- **Royal Luxury Aesthetics**: Dark obsidian & warm gold theme, custom typography (*Cinzel* & *Outfit*), elegant glassmorphism.
- **Sparkling Button Animations**:
  - Interactive Ripple click animations.
  - Hover magnetic 3D lift & golden light shimmer reflection.
  - Glowing pulse buttons & bouncing badge counters.
  - Synthesized Web Audio API tactile feedback sounds.
- **Royal Menu & Smart Search**: Real-time category filtering (BBQ, Mains, Starters, Fast Food, Desserts, Beverages) and live search bar.
- **Cart & Slide-out Checkout Drawer**: Add dishes, adjust quantity, apply promo code `MEERZAIB10` (10% OFF), select Delivery / Pickup / Dine-in.
- **VIP Table Reservation**: Pick date, time, number of guests, and seating preference (Royal Hall, Open Air Rooftop, VIP Lounge, Family Cabana).
- **Patron Reviews**: Read testimonials and submit new customer ratings with interactive star selectors.

### 2. 🛡️ Staff & Manager Admin Panel (`admin.html`)
- **Secure Login Gate**:
  - **Username**: `admin`
  - **Password**: `meerzaib123`
- **Executive Analytics Dashboard**: Live metrics for Total Orders, Revenue (Rs.), Table Bookings, and Active Menu items.
- **Orders Management**:
  - Track incoming customer orders live.
  - Update status: `Pending` ➔ `Preparing` ➔ `Completed` / `Cancelled`.
  - Print formal thermal receipt / customer invoice.
- **Menu Items CRUD**:
  - Add new dishes with photos, price, category, rating, and special tags.
  - Edit or delete dishes.
  - Reset to default signature royal dishes with 1-click.
- **Table Reservations Manager**: Approve or cancel reservations.
- **Feedback & Review Moderation**: View customer submissions.
